# Task List Application

A task management application developed to help users organize and track their daily tasks. The project provides a simple and user-friendly interface for creating, updating, and managing tasks.

## Features
-Add new tasks
-Update existing tasks
-Delete tasks
-Mark tasks as completed
-Simple and user-friendly interface
-Task organization and tracking

##Technologies Used
-Python
-Flask
-HTML
-CSS
-JavaScript

##Purpose

The purpose of this project is to provide a lightweight task management solution while improving backend and frontend development skills.

##Installation

1. Clone the repository:
  git clone https://github.com/your-username/task-list.git

2. Install dependencies:
  pip install -r requirements.txt

3. Run the application
  python app.py

4. Open your browser and visit:
  http://localhost:5000
